## 🚀 Quick Start

```bash
git clone <YOUR_REPO_URL>
cd groove
npm install
cp src/config.example.json src/config.json
# edit src/config.json
node --no-warnings Shard.js
```

---

## ⚙️ Configuration

Copy `src/config.example.json` → `src/config.json` and fill in:

| Key | Description |
|-----|-------------|
| `token` | Your Discord bot token |
| `prefix` | Prefix for text commands |
| `ownerID` | Array of owner Discord IDs |
| `links.support/invite/guild` | Your server links |
| `nodes` | Lavalink node(s) |

> ⚠️ **Never** commit your real `config.json` — it contains secrets. It is already listed in `.gitignore`.

---

## 📡 Lavalink

A running Lavalink v4 node is required. Configure it in `src/config.json` (`nodes`).
